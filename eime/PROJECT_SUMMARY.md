## 🚀 How to Use

1. **Install dependencies:**
   ```bash
   cd eime
   npm install
   ```

2. **Populate demo data:**
   ```bash
   npm run demo
   ```

3. **Start the server:**
   ```bash
   npm start
   ```

4. **Open dashboard:**
   Navigate to `http://localhost:3000`

---

## 📊 API Endpoints Available

### Emotional Data Layer
- `POST /api/analyze-sentiment` - Analyze text sentiment
- `POST /api/analyze-emotion` - Detect emotions in text

### AI-EI Translator
- `POST /api/generate-emotional-profile` - Get user emotional profile
- `POST /api/map-behavior-to-emotion` - Map behaviors to emotions

### Empathy Engine
- `POST /api/recommend-tone` - Get tone recommendations
- `GET /api/user-trust-score/:userId` - Get user trust score

### Trust Dashboard
- `GET /api/dashboard/overview` - Dashboard overview
- `GET /api/dashboard/metrics` - Detailed trust metrics
- `GET /api/dashboard/trust-loop` - Trust Loop analytics
- `GET /api/users/:userId/trust-paradox-level` - User trust level
